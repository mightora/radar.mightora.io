What is a technology radar?

A technology radar is a picture of the technologies your team is considering, adopting or retiring. Each dot is one CSV row. Category divides the radar into sectors; Status chooses a ring; Dot Status adds a separate marker style.

This editor uses the configured ring order, from Assess on the outside to Decommission at the centre. Distance from the centre is not a score or a recommendation. Sub Category is recorded with each technology but does not create another sector.

The app opens on Preview. Use Radar to choose a named radar or All radars. Hover or focus a dot to inspect its CSV values. Toggle labels shows or hides technology names; Reset view returns the radar selection to All radars.

Quick start

  1. Open the editor and choose a dataset from Load example, or use Upload CSV to choose a local CSV file. Download your current source first if you need to keep it.
  2. Open Editor, then choose Visual for a table of fields or CSV for the text source. Change a technology or add a row.
  3. Wait for validation, which runs 300 ms after your last edit. Check Errors and fix any reported issues.
  4. Open Preview to inspect the radar. While errors remain, it shows the last valid version.
  5. Use Download CSV to save an editable copy. Open Exports for other formats, or read the privacy warning before using Share.

To start from scratch, choose New, then Editor → Visual → Add row. New leaves the six-column CSV header in place. Fill every field before expecting a new preview.

Loading an example

The Load example list includes Power Platform Radar, Software Development Radar, Enterprise Architecture Radar, Cloud & DevOps Radar, Data & AI Radar, Cybersecurity Radar and Frontend Web Radar. Choose one to replace the current source.

If you have changed the source, the editor asks before replacing it. Cancel keeps your work. If an example cannot be fetched, a message appears and your source stays unchanged. Undo restores the source from before a successful example load; Redo reapplies it.

Visual editor

In Editor, choose Visual. Edit text fields directly and choose Status and Dot Status from their lists. Radar Name, Category and Sub Category offer suggestions from your current data. Changes update the same CSV used by the CSV editor, sharing and downloads.

  • Add row appends a row and focuses its first empty field. It uses the selected radar, if any, and defaults to Assess and Standard. It also clears the text filter.
  • Duplicate copies all values. Change the copy to clear the duplicate-entry error.
  • Delete removes that row. Deleting the last row keeps a valid, header-only CSV.
  • Move up and Move down swap with the adjacent row in CSV order, including rows hidden by filters. Each row action is one Undo step.

The row buttons have accessible names such as Move up row 2 and Delete row 2. Use Tab to move between fields and buttons. Undo and Redo also cover visual cell edits; use the toolbar buttons or Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z and Ctrl/Cmd+Y.

Filter rows searches all six columns without case sensitivity. Filter by radar uses the same selection as Preview. Clear filters shows all rows again. Filters only hide rows: downloads and share links still include them. Filter changes do not add undo steps.

Malformed CSV makes the visual editor read-only. Choose Switch to CSV to fix to repair it; switching modes never discards the invalid source. The browser remembers your Visual/CSV preference.

CSV editor and required columns

Choose Editor → CSV to edit the CSV radar source. Use these six column names in exactly this order, including spaces and capitalisation:

Radar Name,Category,Sub Category,Technology,Status,Dot Status
Radar Name
The radar this technology belongs to. One CSV may contain several named radars.
Category
The sector containing the dot, such as Platform or Data.
Sub Category
A further grouping recorded with the dot, such as Runtime or Storage.
Technology
The name displayed beside the dot.
Status
The ring label, using an exact value from the status list below.
Dot Status
The marker label, using an exact value from the dot-status list below.

Every row needs all six fields. Wrap a field containing a comma, quote or newline in double quotes; write a literal quote as two double quotes. For example:

Radar Name,Category,Sub Category,Technology,Status,Dot Status
Team Radar,Platform,Runtime,"Example, Inc. ""Engine""",Trial,Standard

Format CSV rewrites parseable CSV with consistent quoting and line endings. It does not repair validation errors. Use Upload CSV to replace the source with a local file, and Download CSV to save the current source, including any errors you are still fixing.

Statuses and dot statuses

Status determines the ring. The following list is ordered from outside to centre and follows radar-definition.yaml. Use these exact labels in CSV.

Assess
Explore and understand its potential.
Trial
Test through a controlled pilot.
Deploy
Approved for active adoption.
Sunset
Avoid for new work and plan replacement.
Decommission
Remove from service.

Dot Status is independent of the ring. It communicates whether the technology is standard, comes with caveats, or is rejected in your team's context:

Standard
A dark filled circle for a standard choice.
Caveated
A blue filled circle for a choice with conditions or caveats.
Rejected
A red outlined ring for a rejected choice.

The radar's legend shows both sets of labels. These are your data's decisions, not automatic recommendations from the editor.

Validation errors

Validation runs after a 300 ms pause in typing. Errors shows the error count and messages with CSV line numbers; the header is line 1. Visual cells also show their relevant messages.

  • Headers must be exactly…: restore the six required column names in order.
  • Unclosed quoted value.: close the quoted field in CSV mode, and double any quotes inside it.
  • Cannot be empty messages: fill in Radar Name, Category, Sub Category and Technology.
  • Invalid value: choose one of the exact configured Status or Dot Status labels.
  • Duplicate technology entry.: two rows have identical values in every column. Edit or delete the duplicate.

Invalid source is preserved. Preview keeps the last valid radar until all errors are fixed. If the initial source is invalid, there may be no earlier valid radar to display. Check Errors before sharing or exporting: CSV, project and share links contain the current source, while visual exports use the displayed preview.

Sharing

Read the privacy warning, then choose Share. Select View link to open Preview with the Editor panel hidden, or Edit link to open Editor. Select Generate link, then Copy link. If copying is unavailable, select and copy the Generated URL yourself. Close or Escape dismisses the dialog.

Share privacy warning

Anyone with this link can read the radar data. It is encoded and compressed, but it is not encrypted. Do not include confidential information.

A share link contains the whole current CSV, including rows hidden by filters, plus the selected radar name when set. It is a snapshot: later edits do not update an existing link. Opening a valid share link loads its source ahead of the source saved in that browser and replaces that saved source.

A View link is a presentation choice, not access control. There is no link expiry, revocation or live collaboration. Large links may exceed browser or messaging limits; use a CSV download instead. Compression support is required; if the browser reports that compressed sharing is unavailable, download the CSV.

For developers, docs/sharing.md is the technical reference for share payload v1.

Exports

Choose Exports. Files are generated locally in your browser.

CSV
Download the current editable source, including all radars and hidden rows. This is the same source saved by Download CSV, and it can be loaded with Upload CSV.
.radar.json
Download a portable project containing the CSV and format metadata. The current Upload CSV control only accepts CSV; there is no project JSON importer.
SVG
Download the displayed radar graphic as a vector image.
PNG
Download the displayed radar graphic as a raster image.
Print
Open the browser's print dialog. Check its print preview before printing or saving to PDF.

Choose the Radar selection and label visibility in Preview before exporting an image. Resolve validation errors if you want the image to reflect your latest source.

Using on mobile

The toolbar wraps on small screens. Open the header's navigation menu to find Documentation and GitHub. The workspace tabs give access to Editor, Preview, Errors and Exports.

Visual mode shows a labelled card for each row on narrow screens, so you can work through the fields vertically. CSV mode keeps line numbers beside the text. In Preview, the radar fits the width and the legend moves below it. Toggle labels can reduce visual clutter.

The Share dialog scrolls if its contents are taller than the screen. With a keyboard, use Tab and Shift+Tab to move between controls, Enter to activate links and buttons, and Escape to close Share.

Privacy and data

CSV editing, validation, share-link generation and exports happen in your browser. There are no accounts, product backend, server-side CSV storage, analytics or tracking added by this app.

Your source is saved in this browser's local storage, along with your Visual/CSV preference. It is not synchronised between devices. Browser settings, private browsing or clearing site data can remove it; keep CSV downloads as backups. Undo history belongs to the current page session and is lost on reload. Clearing this site's stored data in browser settings removes its saved source and preference.

The browser still makes network requests for site files, configuration, examples, shared Mightora components, fonts and images. Your CSV is not included in those ordinary requests. A shared URL carries the CSV in its fragment, after #, rather than sending it to the static host. Anyone or any service you give the full link to can decode its contents; see the share privacy warning.

Downloads and copied links remain wherever you save or send them. Clearing browser storage does not delete those copies or revoke a link.

FAQ

Why has my preview stopped updating?

The source has validation errors, so Preview is retaining its last valid version. Open Errors, fix each issue and allow 300 ms after the last edit.

Can I keep multiple radars in one CSV?

Yes. Give rows different Radar Name values, then use Radar in Preview or Filter by radar in Visual mode to choose one. Downloads and share links still include the entire source.

Is a View link private or protected?

No. Anyone with either type of link can decode the CSV. View hides the Editor panel; it does not encrypt the data or enforce permissions.

Can someone else's edits change my shared radar?

No. A link is a snapshot and each browser edits its own copy. Send a newly generated link to share a later version.

How do I back up and reopen my work?

Use Download CSV, then Upload CSV when you want to reopen it. Local storage is a convenience, not a backup; the current app does not import .radar.json projects.

Does this require an account or upload my CSV?

No account is needed and the editor processes CSV locally. You decide whether to send a share link or downloaded file to anyone else.

Can I read this guide without JavaScript?

Yes. The guide and its section links are static HTML. The interactive radar editor requires JavaScript.
